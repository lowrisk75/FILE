**Compliance status**: ✅ Compliant

---

#### 5(1)(c): Data Minimization

**Requirement**: Personal data shall be adequate, relevant and limited to what is necessary.

**Implementation**:
- ✅ IP addresses **hashed immediately** with HMAC-SHA256
- ✅ Hashes **not reversible** (secret rotated on boot)
- ✅ Peer IDs **generated by clients**, relay never sees identity
- ✅ Packet payloads **relayed opaquely**, relay never inspects content
- ❌ No logging of IP addresses (only hashed IPs in metrics)
- ❌ No storage of user data (stateless relay)

**Evidence**:
```rust
// relay-server/src/state.rs
pub fn hash_ip_address(ip: &IpAddr, secret: &[u8; 32]) -> u64 {
    let mut mac = Hmac::<Sha256>::new_from_slice(secret)
        .expect("HMAC can take key of any size");
    
    match ip {
        IpAddr::V4(addr) => mac.update(&addr.octets()),
        IpAddr::V6(addr) => mac.update(&addr.octets()),
    }
    
    let result = mac.finalize();
    let bytes = result.into_bytes();
    u64::from_be_bytes(bytes[0..8].try_into().unwrap())
}
```

**Audit trail**:
- Code review: `relay-server/src/state.rs` lines 45-60
- Test: `cargo test test_ip_hashing`

**Compliance status**: ✅ Compliant

---

#### 5(1)(e): Storage Limitation

**Requirement**: Personal data shall be kept for no longer than is necessary.

**Implementation**:
- ✅ **Zero persistent storage** — relay is stateless
- ✅ **In-memory only** — all state discarded on shutdown
- ✅ **Peer timeout: 5 minutes** — inactive peers automatically removed
- ✅ **IP hash secret rotated on boot** — hashes not valid across restarts

**Evidence**:
```rust
// relay-server/src/state.rs
const PEER_TIMEOUT: Duration = Duration::from_secs(300); // 5 minutes

// Cleanup task runs every 60 seconds
async fn cleanup_stale_peers(&self) {
    let now = Instant::now();
    self.peers.retain(|_, peer| {
        now.duration_since(peer.last_seen) < PEER_TIMEOUT
    });
}
```

**Data retention policy**:
| Data Type | Retention | Justification |
|-----------|-----------|---------------|
| Peer registration | 5 minutes (timeout) | Operational necessity |
| IP hash | Until peer timeout | Rate limiting, DoS protection |
| Packet payloads | Immediate relay (microseconds) | Transit only, no storage |
| Metrics | 30 days (Prometheus) | Operational monitoring |

**Compliance status**: ✅ Compliant

#### 5(1)(f): Integrity and Confidentiality

**Requirement**: Personal data shall be processed securely.

**Implementation**:
- ✅ **IP hashing**: HMAC-SHA256 with per-boot secret
- ✅ **DoS protection**: CAPoW + rate limiting
- ✅ **No plaintext logging**: Only hashed IPs in logs
- ✅ **In-transit encryption**: QUIC with TLS 1.3 (future: Noise XX)
- ✅ **Security hardening**: Non-root, read-only filesystem, no capabilities
- ✅ **Audit logging**: All authentication attempts logged

**Security controls**:
1. **Access control**: Kubernetes RBAC, pod security policies
2. **Encryption**: TLS 1.3 for control plane, QUIC for data plane
3. **Monitoring**: Prometheus alerts for security events
4. **Incident response**: Alert runbook, post-mortem process

**Compliance status**: ✅ Compliant

**Checklist**:
- [ ] Review security audit logs (last 90 days)
