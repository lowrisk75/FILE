### Color Usage
- **#1A1A1A** : App backgrounds, terminal, CLI
- **#7C3AED** : Active connections, secure status, brand highlights

- **#FBFBFD** : Light mode (website, docs)
- **#10B981** : Connected, authenticated, secure
- **#EF4444** : Disconnected, threat detected, alert

## 🔤 Typography

### Primary Font
**SF Pro** (Apple platform native)
- Display : SF Pro Display (headlines, large UI)
- Text : SF Pro Text (body, UI labels)
- Rounded : SF Pro Rounded (friendly contexts)

### Monospace Font
**SF Mono** (code, terminal, logs)
- Regular : Technical docs, code samples
- Semibold : Highlighted code, important logs

### Fallbacks
- macOS/iOS : SF Pro (native)
- Linux : Inter / Roboto
- Windows : Segoe UI
- Web : system-ui, -apple-system

## 📐 Logo Usage Guidelines

### ✅ DO
- Use on dark backgrounds (#1A1A1A, #000000)
- Maintain aspect ratio
- Clear space minimum: 20px all sides
- Use official colors (#7C3AED primary)
- ASCII logo in terminal, CLI, README

### ❌ DON'T
- Stretch or distort
- Change colors arbitrarily
- Add effects (drop shadow, glow)
- Place on busy backgrounds
- Use low contrast combinations

## 🎬 Animation Concepts

### Logo Reveal (3 seconds)
```
Frame 1 (0.0s):  ╱╲            Hexagon appears
Frame 2 (0.5s):  ╱  ╲          
Frame 3 (1.0s):  ╱····╲         Core becomes visible (dots)
Frame 4 (1.5s):  ╱    ╲         Core fades to invisible
Frame 5 (2.0s):  ╱______╲       Final state
Frame 6 (2.5s):  AORATA         Text fades in

### Connection Status (loop)
```
Disconnected:  ○ ────────────  (gray)
Connecting:    ◐ ──●─────────  (animated)
