## 📐 Spécifications Techniques iOS/macOS

### Tailles Requises (iOS)

```
Generate AORATA app icon in ALL required iOS sizes:

- 1024×1024 (App Store)
- 180×180 (@3x iPhone)
- 120×120 (@2x iPhone)
- 167×167 (@2x iPad Pro)
- 152×152 (@2x iPad)
- 76×76 (@1x iPad)
- 60×60 (@3x iPhone spotlight)
- 40×40 (@2x iPhone spotlight)
- 29×29 (@1x Settings)

Requirements:
- NO alpha transparency (opaque backgrounds only for iOS)
- Corners will be masked by iOS (design for rounded square)
- Test legibility at 29×29 (smallest size)
- Maintain design consistency across all sizes

Export: PNG, sRGB color space
```

### Tailles Requises (macOS)

```
Generate AORATA app icon for macOS (all sizes):

- 1024×1024 (Retina)
- 512×512
- 256×256
- 128×128
- 64×64
- 32×32
- 16×16

Requirements:
- CAN use alpha transparency on macOS
- Square icons (no rounding)
- Test legibility at 16×16 (menu bar size)
- Slightly more detail allowed vs iOS (more screen space)

Export: PNG + ICNS format
```

## 🔧 Outils Recommandés

### Midjourney (Recommandé)

```bash
# Dans Discord Midjourney:
/imagine prompt: [coller un des prompts ci-dessus]
  --v 6 --ar 1:1 --style raw --quality 2

# Pour variations:
/imagine prompt: [prompt] --seed 12345 --chaos 20
```

### DALL-E 3 (via ChatGPT Plus)

```
[Coller le prompt directement]

Options:
- Style: Natural (pour réalisme) ou Vivid (pour couleurs vives)
- Ratio: Square (1:1)
- Demander plusieurs variations (4+)
```

### Stable Diffusion (Local)

```
[Prompt] 

Negative prompt: text, letters, words, watermark, signature, blurry, low quality, distorted

Settings:
- Steps: 50
- CFG Scale: 7-10
- Sampler: DPM++ 2M Karras
- Size: 1024x1024
- Model: SDXL ou Realistic Vision
```

### Figma / Sketch (Vector)

```
Pour créer manuellement:
1. Importer forme hexagone
2. Appliquer gradients (#1A1A1A → #7C3AED)
3. Masques pour effet "invisible"
4. Blur & glow effects
5. Export @1x, @2x, @3x
```
